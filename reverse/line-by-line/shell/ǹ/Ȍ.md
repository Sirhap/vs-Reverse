## 逐行说明

### 构造（L10–38）

1. `_matchedTypes = []`，保存 domain。
2. 遍历 `param1`（`m_platforms`）：每项 `{types, filters}`。
3. `ˣ.apply(null, [domain].concat(filters))`：任一 glob 命中则把 `types` 逐个 decode 写入 `_matchedTypes[i]`（**按下标覆盖**，不是 push；本包每平台 types 长度 2，结果 `[ "4399", "sh" ]` 或 `[ "kongregate", "kong" ]`）。
4. `break`：只取**第一个**命中的平台。

本包 filters 解码：

- `*.(((4399(api|pk|dmw|er|en)?|(505|edu)?4399|3387).com)|4399.cn|4399.net)`
- `*.(kongregate|kongcdn).com`

### `ˣ`（L40–55）

对每个 rest：若是 Array 则 fromCharCode。正则：

```
^ + glob.replace(/^\*\./, '(\\S+.){0,}').replace(/\./g, '\\.').replace(/\*/g, '\\S*')
```

`*.4399.com` → `^(\S+.){0,}4399\.com`，匹配 `4399.com` 及任意子域。不是完整 URL，只吃 hostname。

### `§ͅ§`（L57–60）

`param1` 非空且（已在 `_matchedTypes` 里 **或** `ˣ(domain, param1)`）。第二种让 `easy` 也能传一个域名 glob。`ǿ.easy` 对 `easys:["kong"]` 调这个：只有当前平台 types 含 `"kong"` 才为真（Kongregate 站）。

### `§͆§`（L62–65）

types 元素可以是 `[52,51,57,57]`（`4399`）或已经是 `"sh"`。
