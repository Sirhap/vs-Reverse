## 逐行说明

### 构造（L12–16）

保存 raw；`new Ȍ(platforms, get_domain())` 立刻按域名定性平台。

### `get_domain`（L19–46）

与 `FB.get_domain` 同算法：

1. `ExternalInterface.call` 一段 IIFE：优先 `location.ancestorOrigins` 最后一个的 hostname（iframe 真实父页）；否则向上走 `window.parent`（跨域 catch 空）；再退 `document.referrer` 的 host，再 `document.domain || location.hostname`。
2. 失败则 `Security.pageDomain`（若该属性存在）。
3. 再失败：`new Loader().contentLoaderInfo.loaderURL` 抽 host。
4. `file:` → 返回 `"localhost"`。

### `uts` / `gd` / URI 辅助（L48–82）

标准 fromCharCode / getDefinition。`uri_get_protocol` / `uri_get_hostname` 用同一条 URL 正则，分别取 group1 / group3。

### 简单 getter（L84–153）

直接索引 raw。`loading` 本包是 `LOADING_bvn` 类，给 `FB.updateLoadingUI` → `getInstanceBy(..., DisplayObject)`。

### `easy`（L104–123）

遍历 `easys`。元素可以是 charCode 数组或字符串。任一 `platform.hasType(token)` 为真则 easy。本包 `["kong"]`：只在 Kongregate 域名上放宽「无 JS 桥也允许跑」。4399 / 本地 HTTP 都不是 easy → 无 JS 且非 file 时会要求 allowScriptAccess（见 FB）。

### `publishDate`（L155–173）

Number 当时间戳；String 把 `-` 换成 `/` 再 `new Date`；NaN 则 epoch 0。本包 `"2019-4-28 00:00:00"`。

### `latency`（L175–260）

把 raw.latency 收成毫秒：

- Number：原样（本包 `864000000` = 10 天）。
- 纯数字字符串：`parseFloat`。
- `HH:MM:SS` 一类：`split(":")` 从右按 60^n 加权再 ×1000。**注意**：循环写成 `_loc4_.length` 但赋值的是 `_loc5_`，`_loc4_` 此时仍是 `undefined`。这是 FFDec 瑕疵或原字节码寄存器重用；本包走 Number 分支，这条死路径不影响 3.3。
- `(\d+[a-z]+)+`：`year/month/day/hour/minute/second/ms`（month=30 天，year=365 天）。

`FB.start_remote(true, serverDate)`：若 `now - publishDate < latency` 则**不拉**远程更新（发布后 10 天内跳过 `data.vsgod.win`）。`forceSH=false` 时 `set_hold` 不会带 `true`，localhost 独立版在 `appAdded` 后 `start_remote(false)` 也不做这个比较。
