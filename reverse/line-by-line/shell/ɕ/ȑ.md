### `§ͥ§` materializeApp（L105–182）

`try` 整段，失败返回 `null`（随后体积门会当成损坏）。

**A. 直接实例**（本包走这里）

`FB.getInstanceBy(def, DisplayObject, ByteArray)`：

- `def` 已是这两个类型之一的实例 → 原样
- Class → `new`
- String → `getDefinitionByName` 再 `new`
- charCode 数组 → 先拼类名

`bleachvsnaruto extends Sprite` → 命中 DisplayObject，返回实例。

**B. `def` 是 Array**（本包不是）

- `length==1` **或** `[1]` 的 typeof 是 `"number"`：把 `[0]` 当素材，`getInstanceBy(..., ByteArray, DisplayObject)`。若得到 ByteArray 且还有后续项：把 `[0]` 换成这份 BA，`new ByteArray().writeBytes.apply(null, arr)`——即 `writeBytes(src, offset, length)` 切片。然后 `src.clear()`。
- 否则当**拼接列表**：逐元 `getInstanceBy` 成 BA 追加；元自身还是数组则同样按 offset/length 切片。最后 `length>0` 才采用。

这是把 SWF 拆成多个 ByteArray 符号再拼回去的路径，发行包未用。
