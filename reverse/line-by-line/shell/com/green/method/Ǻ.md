# `com.green.method.Ǻ` — 页面 embed/object 的 JS 桥

一句话目的：用 `ExternalInterface` 定位当前 SWF 的 `<embed>`/`<object>`，读写 PARAM，必要时 `cloneNode` 替换以修正 `allowScriptAccess` 等。FB 只用 `ɯ`、`ʽ`、`ʾ`、`reload`。

源文件：`decompiled/main/scripts/com/green/method/Ǻ.as`（777 行）

## Callers / callees

- **Callers**：`FB.init_fb` 在 `ǻ.ˌ`（网页）且 `Ǻ.ɯ`（JS 可用）时：`ʾ()` 取默认 PARAM，`ʽ(name, current)` 读实际值，不符则 `reload(0, null, fixedParams)`。
- **Callees**：`ExternalInterface.call` / `addCallback`；大量内联 JS（fullscreen、location、download）。

## 逐行说明

### 探测 JS 是否可用

- **`ɯ`（L45–51）**：首次 `eval("true")==true` 后缓存。失败则整座桥停用，`reload` 直接 return。
- **`eval` / `call` / `ʑ` / `ʓ` / `ʔ`（L190–420）**：`ʑ` 是 `ExternalInterface.call.apply` 吞异常返回 null。`call` 转 `ʑ`。`ʓ` 只关心是否抛错。`ʔ` 失败时想返回 error 对象，FFDec 写成 `§--UNKNOWN--§`（反编译瑕疵）。
- **`addCallback` / `ʗ`（L433–455）**：注册 AS 函数到 JS；失败同样 UNKNOWN 伪代码。`ʗ` 默认名 `f_<random>`。

### 定位当前 SWF DOM 节点

- **`flash`（L54–82）**：`ʗ(new Function())` 在 embed 上挂一个独一无二的回调名 `f`。依次试：`querySelector(object[id=objectID],embed[name=objectID])`、`getElementById`、`getElementsByName` 集合、`document.all`/`getElementsByTagName('*')`。`ɲ` 检查 `f in ele && ele[f] instanceof Function`。找到后 `ɱ` `delete ele[f]` 清掉。
- **`index`（L136–163）**：同样挂随机回调，在 `document.all \|\| getElementsByTagName('*')` 里扫下标，再 delete。
- **`ɰ`（L84–106）**：不用 callback：有 index 则 `all[i]`；否则 `getElementById(objectID)` 或 `getElementsByName(name)[0]`；再不行 `"({})"`。
- **`ɴ` / `ɳ`（L119–133）**：在集合里找带指定函数名的下标，拼成 `expr[i]`。
- **`ɲ` / `ɱ` / `ʘ`（L109–117, L457–460）**：JS 侧 in 检查；delete 属性；对 `flash` 节点删回调。

### 读/写 PARAM 与样式

- **`ʽ(name, fallback)`（L684–695）**：`nodeName==EMBED` → `getAttribute`（`ʯ`）；`OBJECT` → 扫 childNodes 的 `name`（`ʴ`）。这是 FB 核对 `allowScriptAccess` / `allowNetworking` 的入口。
- **`ʾ`（L722–736）**：默认值袋。注意 `allowScriptAccess` 默认 **`samedomain`**（小写），而 `m_app_model.params` 要求 `always`。比较时 `toLowerCase`，所以 `"sameDomain"` vs `"always"` 会触发 reload。
- **`wmode` / `allowNetworking` / `allowScriptAccess` / `allowFullScreen` / `allowFullScreenInteractive`（L697–720）**：`ʽ` 的糖，各自有 fallback。
- **`ʵ/ʶ/ʷ/ʸ`（L636–662）**：nodeName / id / name / 资源 URL（EMBED.src 或 OBJECT 的 movie PARAM / data）。
- **`ʪ/ʫ/ʱ/ʲ/ʳ/ʬ/ʭ/ʮ/ʯ`**：设属性、setAttribute、读属性。`ʰ(w,h)` 改 style 宽高。
- **`getAttribute`（L584–587）**：返回的是 **JS 表达式字符串** `expr.getAttribute`，不是已取值。

### `reload`（L743–774）

`ɯ` 为假则 return。`ʎ(ˀ(urlExpr, overrides), delayMs)` = `setTimeout(js, delay)`。`ˀ` 生成 IIFE：

1. 默认补 `allowNetworking=all`、`allowFullScreen=true`、`allowScriptAccess=always`。
2. `param2` 覆盖（FB 传入缺的那几项）。
3. `cloneNode(true)`；OBJECT 改/加 `<PARAM>`，EMBED `setAttribute`。
4. `parent.replaceChild(new, old)` —— 页面重挂 SWF，等于刷新播放器实例。

FB 在 reload 前 `ǵ.ɐ.dispose()`。

### location / 域

`protocol` `href` `ʜ` parent.href `ʝ` top.href `ʞ` referrer `ʟ` parent.referrer `ʠ` top.referrer `ʡ` document.URL `ʢ` lastModified `domain`（document.domain 优先否则 hostname）`ʤ` `hostname` `ʥ` parent.hostname `ʦ` top.hostname。

**`ʧ`（L557–560）**：从当前 window 向上走到还能读 `document` 的最高层，返回该层 href，跨域则用 referrer。壳未用（域名探测在 `ǿ.get_domain` 另一段 JS）。

**`ʣ`（L522–525）**：解析 `document.lastModified`，与「现在」的 `toLocaleString` 比较 —— 页面是否「今天改过」。壳未用。

**`ʿ`（L738–741）**：缩短 `document.domain` 直到能访问 `window.top.document`（经典跨子域技巧），失败还原。壳未用。

### fullscreen

- **`ɻ`（L231–234）**：一大段 IIFE，探测 `ms/webkit/moz` fullscreenElement 前缀，提供 request/exit/isFullscreen。
- **`ɺ`（L225–229）**：更长的构造函数字符串：听 fullscreenchange，把 embed 父链 width/height 拉满 client，退出时恢复。`ʃ` 把它 `new` 出来。壳未用。
