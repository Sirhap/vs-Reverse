## 逐行说明

### 静态默认（L24–26）

`§̀§ = uint.MAX`（默认几乎不限次）；`§́§ = 2000` ms。

### 构造 / `init`（L48–66）

### `ˬ`（L68–75）

监听 open/progress/complete/ioError/securityError，全部进 `§˯§`。不听 HTTP 状态码；complete 即成功。

### `§˭§` / `ˮ`（L77–137）

`null` 忽略。String → 只设 url。Object → `ˮ`：先抽 `onEvent`，再 switch 已知键（url/ms/reloadDelay/repeat/onStart/…）。其它键静默丢弃。若此时已有 url 且 `param1.start` 为真则 `start()`。

### url / requestHeaders（L139–157）

透传到 URLRequest。

### `start` / `load` / `stop`（L159–191）

- `start`：若 READY 或已结束，刷新 `_tStart`。先 `stop` 清旧请求，再 `§˰§`（START++count），然后 `URLLoader.load`。
- `load(url)` = 设 url + start。
- `stop`：若 isLoading 则 `close()`；若 WAITING 则 `clearTimeout`；若 busy 则拨回 READY。不派 fail。

### `log`（L193–197）

`unshift` 最新到 `[0]`。`logText` 读最新；`§˽§` reverse join 成时间正序。

### `§˯§` 事件分发（L199–229）

open→`§˲§`；progress→`§˳§`；complete→`§˴§`；security→`§˶§`；io→`§˷§`。

### 状态迁移（L231–295）

| 方法 | 状态 | 副作用 |
|------|------|--------|
| `§˰§` | START | ++count，`load_start` |
| `§˱§` | WAITING | `setTimeout(start, ms)` |
| `§˲§` | OPEN | `load_open` |
| `§˳§` | PROGRESS | `load_progress` |
| `§˴§` | DEALING | 立刻 `§˵§`（本类无二次处理） |
| `§˵§` final | COMPLETE | 记 `_tEnd`，`load_complete` |

### `loadBytes`（L307–311）
