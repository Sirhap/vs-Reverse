## 逐行说明

### `§̩§` 重包装（L19–51）

先 `§̬§` 得到未压缩 body，失败抛「目标格式错误」。写出 `param2` 签名 + 原 version byte + FileLength：

- FWS：length = body+8，后跟 body。
- CWS：body.compress("zlib")，length 仍按**未压缩** body+8（SWF 规范 FileLength 是解压后大小）。
- ZWS：length = body+8+8；compress lzma；写 `lzmaPayloadLength-13`，再 5 字节 props + 跳过 13 字节头后的数据。

壳启动路径不调用。

### `§̪§` / `§̫§`（L53–82）

签名白名单。`§̫§` 临时 littleEndian、position=4 读 UI32，再恢复。长度 <8 返回 0。

### `§̬§`（L84–116）

FWS：拷 offset 8 起。CWS：拷 8 起 zlib 解压。ZWS：校验 `[8..11]` LE == `length-17`，然后 `§̭§(...,0)`，失败再 `§̭§(...,-8)`。

### `§̭§`（L118–131）

拼标准 LZMA：5 字节 props（SWF offset 12）+ unpacked size (`FileLength-8+param2`) + 0 + payload from offset 17。`uncompress("lzma")`。

### `§̮§`（L133–205）

解压后从 RECT 之后（FWS position=21；压缩格式解压后 position=13，**假设 RECT 固定吃掉 8+1+2+2？** 这与 nbits 可变矛盾，标 `?`：只对 nbits 导致 header=13 的舞台尺寸可靠）。循环读 tag：short 的高 10 bit 是 id，低 6 是 length，63 则再读 UI32。id==76（SymbolClass）：读 count，每条 skip 16-bit char id，再读到 NUL 的 UTF 名字。其它 tag 跳过 length。

### `§̯§`（L207–210）

`return false`。占位完整性检查，从未实现。

### `§̰§`（L212–224）

若 length>8，把前 8 字节写成随机 `0..254`。`ȑ` 在 inner SWF 已经 `loadBytes` 完成、content 已在内存后调用：破坏 `LoaderInfo.bytes` 的签名/FileLength，让后续再 dump 这份 ByteArray 不像合法 SWF。**不**改磁盘上的 `main.swf`。本包走 DisplayObject 路径时不调用。

### `§̱§`（L226–237）

`readUTFBytes(3)`。FB 用 `/\wWS/.test(sig)` 识别 FWS/CWS/ZWS。
