# `ƒ.ǵ` — FrameManager：停时间轴、三层容器、泵 FrameTask

一句话目的：壳单例。文档类把主 MC 交来之后，停播、叠 app/progress/remote 三层，按已加载帧逐个调用 `[FrameTask]` 静态方法（FA → FB → FC）。

源文件：`decompiled/main/scripts/ƒ/ǵ_2.as`（525 行）。类名是 `ǵ`；`_2` 是 FFDec 为避开与其它 `ǵ` 文件冲突加的后缀。

## Callers / callees

- **Callers**：`BleachVSNaruto` 构造调 `ɐ.Ȱ(this, Ǵ)`。`ƒ.Ǵ` / `ƃ.FB` / `ɕ.ȑ` 大量读容器、loaded、bytesTotal、日志、`dispose`。4399 页通过写到主 MC 上的 `setHold` 注入 Hold。
- **Callees**：`describeType` / `getDefinitionByName` / `ExternalInterface`（全部 `uts` 拼名）；`MovieClip.nextFrame`；自身 EventDispatcher。

## 逐行说明

### 静态槽与构造（L17–49）

```actionscript
private static var ɍ:ǵ = new ǵ();
```

类初始化时构造唯一实例。构造里**先** `new Sprite()` 三次（app / progress / remote），**再** `if (ɍ) throw "不能被实例化"`。第一次构造时 `ɍ` 仍是默认 `null`（赋值发生在 `new` 返回之后），所以能通过；之后再 `new ǵ()` 会先造出三个泄漏 Sprite 再抛错。

三层 Sprite 此时还没有 parent。`Ȱ` 才按 app → progress → remote 的顺序 `addChild` 到时间轴（后加的在上）。

### `ɐ` / `uts` / `ɑ` / `gd` / `ɒ`（L51–75）

- `ɐ` Alias `current`：返回 `ɍ`。
- `uts`：`fromCharCode`。本文件用它隐藏 `ExternalInterface`、`describeType`、`FrameTask`、`setHold`、`loaderInfo` 等字符串。
- `ɑ(fn, ...args)`：`getDefinitionByName("flash.external.ExternalInterface")["call"]["apply"](null, [fn].concat(args))`。EI 不可用时由调用方 `try/catch`。
- `gd`：`getDefinitionByName`。
- `ɒ`：`getQualifiedClassName`。

### `Ȱ` — 文档类入口（L77–103）

`[FrameTask(p2="ƃ", p3="ɕ", c2="FB", c3="ȑ")]` 挂在**本方法**上，供 `ȱ` 读取，不是本方法自己被当任务跑。

`BleachVSNaruto` 调用：`Ȱ(this, Ǵ)`。

1. `Ȭ = param1`（主时间轴）。
2. `Ɏ.length = 0` 清空队列。
3. 把 rest（这里是类对象 `ƒ.Ǵ`）`ȼ` 入队。
4. `for each (ȱ())` 再入队 `"ƃ.FB"`、`"ɕ.ȑ"`。
5. 若 `totalFrames < Ɏ.length` → 抛 `timeline frames length error`。本包 3 帧、3 任务。
6. `Ȭ.stop()`：主时间轴不再按帧率自己走。后续只靠 `ȵ` 的 `nextFrame()`。
7. 叠三层容器。
8. `Ȳ()` 装钩子、读体积水印。
9. 已有 stage 则立刻 `ȳ(null)`，否则听 `addedToStage`。

此后文档类不再执行任何逻辑。

### `Ȳ` 装时间轴钩子（L125–149）

### `ȵ` 泵帧（L182–201）

```actionscript
while (currentFrame < framesLoaded) {
    nextFrame();          // 可能执行该帧上的时间轴脚本
    log "[FM] go to: N"
}
ȹ();
if (loaded) log "[FM] real size:", loaderInfo.bytes.length
```

`nextFrame` 抛错只记日志，不中断循环条件（若 `currentFrame` 没涨可能死循环？——播放器通常会前进或停在末帧；标记 `?`：极端坏帧脚本下的行为未静态证实）。

`ȹ` 用的是 `framesLoaded` 当「可跑到的任务下标」，不是 `currentFrame`。流式加载：第一次只跑 FA；后续 progress 再 `ȵ` 把 FB、FC 补上。

### `Ȣ` / `ȶ` 转发（L203–229）

每次 loaderInfo 事件先 `ȵ()`（让新到达的帧变成任务），再 `switch` 里对五类都 `ȶ(event.clone())`。`init` 与 `progress` 共用一条。`ȶ`：仅当 FM 上 `willTrigger(type)`（已有监听）才 `dispatchEvent`。FA 在未 loaded 时听这几类；FC 在未 loaded 时听 `complete`。

### `ȷ` setHold（L231–235）

`Ȩ = param1`，派 `Event("change")`。`Ʉ` 的 setter 也走这里。FB 在 4399 路径听 `change` 再 `set_hold`。值为任意 `*`（页面注入的 Hold 对象）。

### `ȸ` 按名滤 metadata（L237–252）

`describeType(obj).elements("*")["metadata"]`，留下 `@name == param2` 的节点。对实例：实例方法/存取器上的 metadata；对 Class：静态成员上的。`ȹ` 对**任务类对象**调它来找 `[FrameTask]`。

`describeType` / `metadata` / `name` / `*` 均 `uts` 拼出。

### `ȹ` 跑 FrameTask（L254–300）——核心

```

    if ȩ < 队列长度:
```

本包队列：

| ȩ | 项 | 方法 |
|---|-----|------|
