# `loading_fla.元件8_17` — 嵌套加载动画（F1 停 / F10 COMPLETE）

一句话目的：loading.swf 内部元件。F1 停着；播到 F10 再停并派 `Event.COMPLETE`。引擎不按链接名 `createDisplayObject`，只作为某条加载 UI 时间轴里的嵌套动画。

源文件：`decompiled/ui/loading/scripts/loading_fla/元件8_17.as`（40 行）

## 如何挂上引擎

无直接调用方。名字是 Flash 默认「元件 8」+ FFDec 后缀 `_17`，不是给 [`ResUtils`](../../../../engine/game/bvn/utils/ResUtils.md) 用的链接名。

可能嵌在 [`loadingbar_mc`](../loadingbar_mc.md) 的内层 `bar`、或封面/战前加载 MC 的装饰层：时间轴从停帧播到 F10，通知父级「这段动画完了」。引擎读写的进度是 `bar.bar.scaleX` / `txt.text`，**不**听本类 COMPLETE。

对比 [`winner_stg_mc`](../winner_stg_mc.md) F92 的 COMPLETE：那条引擎真听。本类 COMPLETE 只给 FLA 内部衔接。
